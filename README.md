# Science Blog Website

> A multi-page science blog covering AI, Space, DNA, Climate, Quantum Computing and Ocean Science.

![HTML](https://img.shields.io/badge/HTML-65%25-orange?logo=html5) ![CSS](https://img.shields.io/badge/CSS-28%25-blue?logo=css3) ![JavaScript](https://img.shields.io/badge/JavaScript-4.6%25-yellow?logo=javascript)

## What It Is

A fully structured science blog website built from scratch — no frameworks, no templates. Each topic has its own dedicated page with custom styling.

## Pages

| Page | Topic |
|---|---|
| `home.html` | Landing page & navigation |
| `ai.html` | Artificial Intelligence |
| `space.html` | Space Exploration |
| `dna.html` | DNA & Genetics |
| `climate.html` | Climate Change |
| `quantum.html` | Quantum Computing |
| `ocean.html` | Ocean Science |

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP (form handling)
- **Database:** MySQL (contact/newsletter form)

## What I Learned

- Building multi-page sites with consistent navigation and layout
- Writing custom CSS per page without a framework
- Connecting HTML forms to a PHP/MySQL backend
